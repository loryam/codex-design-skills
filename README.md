# Design skills

Two reusable skills for designing and maintaining product interfaces.

| Skill | Purpose |
| --- | --- |
| [Design Meaningful Interfaces](design-meaningful-interfaces/SKILL.md) | Communicate product purpose through visual hierarchy, grouping, state, and interaction. |
| [UI Consistency Guardian](ui-consistency-guardian/SKILL.md) | Keep typography, tokens, spacing, components, accessibility, and responsive behavior consistent with an existing design system. |

Each folder includes the original skill instructions, agent metadata, and supporting references. UI Consistency Guardian also includes an optional Python script for scanning frontend code for common design drift indicators.
